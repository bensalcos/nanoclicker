# NanoClick status

Updated: 2026-10-24.

- **Plan:** architecture, UI specification, phases and backlog are documented. T01 is complete with the unavailable C++ Windows baseline explicitly pending. Platform milestones remain open.
- **Language:** the new application uses English throughout.
- **Implemented:** three-crate Rust workspace; validated plans, monotonic scheduling, cancelable worker, terminal snapshots; light/dark/system themes, three mouse buttons, infinite/count modes, manual countdown, native Windows/X11 shortcuts and Wayland portal adapters.
- **Verified locally:** 39 Rust tests (22 core, 14 application, 3 Windows helpers), plus 3 Python packaging tests. Linux Clippy, Windows MSVC target Clippy/tests compilation, alternate wgpu feature Clippy and Rust 1.95 compatibility checks pass. Native Windows test execution passes in hosted CI; desktop execution remains pending.
- **UI:** five form/select controls expose accessible names and values. Tests cover Tab/Shift+Tab order, Enter in fields, token contrast and primary-action bounds in all run states with long errors/counters. Session status is a polite atomic live region. See [accessibility evidence](evidence/ui-accessibility.md).
- **X11 runtime:** actual GUI flows pass in private Xvfb at 100/150/200%, including minimum 420×520 logical size, manual countdown, shortcut outside focus, complete pairs, no post-stop input and clean close. Default-size help clipping is fixed; a visible scrollbar serves smaller windows. Updated light/dark, minimum and active-state captures are in [scaling evidence](evidence/ui-scaling.md).
- **Input/shortcuts:** isolated X11 adapter tests received ordered pairs for all three buttons and checked held F6 and conflicts. Windows/X11 shortcut listeners use events rather than polling. The worker uses a portable condition variable on Linux and a high-resolution timer plus per-run cancellation event on Windows; see [wait evidence](evidence/native-waiter.md).
- **Windows:** cross-target checks pass; hosted Windows Server 2025 now passes 42 native Rust tests and the MSVC release build/link. Windows ZIP/PDB packaging now has a CI build and verification step; its first hosted result and desktop GUI execution remain pending. Native SendInput, timer/hotkey performance, installation, DPI and NVDA remain pending.
- **Wayland:** local GNOME exposes RemoteDesktop v2 and GlobalShortcuts v1. Closed and service-owner listeners are installed before permission preparation. Consent, denial, revocation, isolated D-Bus lifecycle tests, actual native input and KDE remain pending; see [lifecycle evidence](evidence/wayland-lifecycle.md).
- **Preferences:** explicit Save, versioned schema, atomic replacement and recovery tests pass on Linux. Running state/permissions are never restored. Native Windows filesystem regression tests now pass on the hosted Server 2025 runner; desktop Save/relaunch QA remains pending.
- **CI:** pinned Linux/Windows workflow and MSRV/renderer jobs are prepared; run 40090868511 at e71fc32 passed all four hosted jobs after fixing the Windows preferences bug. Downloaded X11 logs were inspected. See [CI evidence](evidence/ci.md) and [Windows preferences](evidence/windows-preferences.md).
- **License:** MIT notice is Copyright (c) 2026 bensalcos, chosen after the user's explicit delegation.
- **Packaging:** Linux previews include dependency notices, verified MPL source, checksums and separate symbols. The refreshed UI preview in `dist/preview-x11-checked-pairs/` passed the isolated Ubuntu GUI flow, including minimum size; checksums verified. It remains a local preview, not an accepted release. See [packaging evidence](evidence/packaging.md).
- **Dependency audit:** no known vulnerabilities and three upstream maintenance warnings, recorded without ignores in [audit evidence](evidence/dependency-audit.md).
- **Performance:** the matched-source pre-polish comparison measured glow/wgpu active CPU at 5.23%/6.03% of one core and idle RSS at 107.23/104.53 MiB. Both exceeded the unchanged CPU/RAM budgets; glow remains provisional. The current accessible UI release measured 73.712 ms startup p95, 0 observed idle CPU ticks, 106.789 MiB idle RSS and 5.3499% active CPU. CPU/RAM budgets remain unmet; see [current UI measurements](evidence/ui-polish-performance.md). The checked-pair optimization removes one native send/poll per X11 pair; total CPU/RAM remain above budget. ThinLTO screening was rejected as neutral. The 4,000 no-input core Stop samples do not replace native input/GUI latency evidence. See [renderer comparison](evidence/renderer-comparison.md).
- **Remaining:** CPU/RAM optimization and deadline-lateness measurements; native Windows/GNOME/KDE validation; real monitor transitions, NVDA/Orca and final distribution acceptance. Keep the C++ reference until those gates close.

See [plan](../tasks/plan.md), [tasks](../tasks/todo.md) and [implementation evidence](evidence/implementation.md). Compilable adapters, synthetic scaling and headless accessibility tests do not close native acceptance gates.
