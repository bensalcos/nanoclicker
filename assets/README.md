# Application assets

`nanoclick.png` is the first 256×256 PNG payload extracted byte-for-byte from the repository's original `Autoclicker.ico`. No pixel conversion or redesign was performed. The original remains the C++ migration reference. It remains the supplied legacy icon; the user delegated project attribution to the repository owner, bensalcos (2026).

The desktop entry expects `nanoclick` on PATH and the icon installed into the user's icon theme. The preview bundle includes installation instructions; it does not install anything automatically.
